Как это работает

Без root-прав и облака. Только ваш телевизор.

  1. 1

    Разрешите один раз

    Включите меню «Для разработчиков» и подтвердите запрос «Разрешить отладку по USB?» на телевизоре. Это единственное разрешение, которое ему нужно.

  2. 2

    Он заменяет главный экран

    Через собственный ADB телевизора (localhost: ничего не уходит за пределы телевизора) он становится главным экраном и заставкой, отключает заводской лаунчер и короткий список рекламных приложений. Ничего не удаляется.

  3. 3

    Откатить можно в любой момент

    Одна кнопка возвращает заводской главный экран, заставку и все приложения. Если что-то пойдёт не так, Free My TV сам вернёт заводской.

Установка

Около десяти минут, от начала до конца.

Бесплатно, с открытым кодом и легко откатить.

  1. На телевизоре: Настройки → Система → Об устройстве, 7 раз нажмите Сборка ОС Android TV. Вернитесь назад, откройте Для разработчиков и включите Отладку по USB. Запишите IP-адрес телевизора (Настройки → Сеть и Интернет).
  2. На компьютере: скачайте код.
    git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv
  3. Откройте Claude Code в этой папке и скажите:
    Установи Free My TV на телевизор 192.168.1.50. Я живу в Москве.
    Он установит нужные инструменты, соберёт приложение и поставит его на ваш телевизор. Замените IP-адрес и город на свои.
  4. Теперь на телевизоре: откройте Free My TV → Главный экран → Free My TV и подтвердите запрос на отладку, отметив Всегда разрешать с этого компьютера.
  1. На телевизоре: включите Для разработчиков и Отладку по USB (как на другой вкладке) и запишите его IP-адрес.
  2. Инструменты: JDK (17+), инструменты командной строки Android SDK и adb. На Mac:
    brew install --cask temurin android-commandlinetools android-platform-tools && sdkmanager "build-tools;34.0.0" "platforms;android-34"
  3. Сборка: при первом запуске создаётся config.properties. Впишите туда свой город, а для рекомендаций возьмите бесплатный ключ TMDB. Затем соберите снова.
    git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv && ./build.sh
  4. Установка:
    adb connect 192.168.1.50:5555 && adb install -r FreeMyTV.apk
    На телевизорах TCL также разрешите ему работать в фоне (TCL блокирует это по умолчанию):
    adb shell "appops set io.freemytv AUTO_START allow || appops set io.freemytv APP_AUTO_START allow"
  5. На телевизоре: откройте Free My TV → Главный экран → Free My TV.
  1. На телевизоре: в LG Content Store установите Developer Mode. Войдите в бесплатный аккаунт разработчика LG, включите Dev Mode Status (телевизор перезагрузится), затем включите Key Server (сервер ключей). Запишите IP-адрес и кодовую фразу, которые покажет приложение.
  2. На компьютере: скачайте код и соберите приложение для LG. Добавьте город в config.properties, как для Google TV.
    git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv && python3 webos/build.py
  3. Установка: введите кодовую фразу телевизора, когда скрипт попросит. Free My TV откроется на экране телевизора.
    python3 webos/install.py 192.168.1.50
  4. Быстрый доступ: пока приложение открыто, удерживайте цифровую кнопку на пульте. С этого момента она открывает Free My TV откуда угодно. Раз в месяц нажимайте EXTEND в Developer Mode, чтобы сохранить доступ.
  1. На телевизоре: откройте Приложения и наберите на пульте 1 2 3 4 5. Включите Режим разработчика, введите IP-адрес компьютера в поле Host PC IP и перезагрузите телевизор.
  2. На компьютере: скачайте TizenBrew Installer, установщик от сообщества для телевизоров Samsung. Откройте его и подключитесь к телевизору.
  3. Установка с GitHub: введите строку ниже. На телевизорах 2023 года и новее установщик один раз попросит войти в аккаунт Samsung, чтобы подписать приложение для вашего телевизора.
    simbasjungles/free-my-tv
  4. Сразу в приложение: в настройках телевизора, в параметрах начального экрана (Start Screen Options) включите Автозапуск последнего приложения: телевизор будет включаться сразу в Free My TV. Город эта сборка берёт из часового пояса телевизора. Чтобы указать точный город и получать рекомендации, Claude Code соберёт приложение с вашими настройками.

Частые вопросы

Хорошие вопросы.

Это безопасно?

Он использует те же команды, что и встроенные инструменты разработчика Android, и работает прямо внутри телевизора. Никаких root-прав, ничего не удаляется: приложения только отключаются и возвращаются одной кнопкой. Изображение, звук, входы, пульт, сервисы Google и Play Store он не трогает никогда.

Как вернуться к заводскому?

Откройте Free My TV → Главный экран → Заводской. Заводской главный экран, заставка и все приложения вернутся ровно такими, какими были. Если новый главный экран упадёт три раза за пять минут, Free My TV сам вернёт заводской.

Меняется ли качество картинки?

Нет. Настройки изображения не меняются, а видео идёт тем же аппаратным путём. Замеры показали одинаковое разрешение и тот же источник видео в обоих режимах.

Что отключается?

Заводские главный экран и заставка (их заменяют), запасной главный экран Google TV, Play Games и YouTube Music, а на телевизорах TCL: TCL Channel, сообщения, демонстрация для магазинов, меню для отелей, руководства, приложения для зеркалирования экрана и сбора логов. Google Assistant отключается, только если вы попросите об этом в config.properties.

Работает на телевизорах LG?

Да. На LG он устанавливается через собственный Developer Mode от LG, без root-прав и без изменений в телевизоре, и открывается одним нажатием цифровой кнопки. Тот же главный экран, те же рекомендации, погода и курсы. Раз в месяц нажимайте EXTEND в приложении Developer Mode, чтобы сохранить доступ.

Работает на телевизорах Samsung?

Да, на телевизорах Samsung с 2017 года и новее. Установка идёт через собственный режим разработчика Samsung с помощью TizenBrew Installer, установщика от сообщества, без root-прав и без изменений в телевизоре. Тот же главный экран, погода и курсы, а город берётся из часового пояса телевизора. Для рекомендаций Claude Code соберёт приложение с вашим бесплатным ключом TMDB.

Можно переделать под себя?

В этом и смысл. Откройте папку в Claude Code и просто попросите: «добавь Crunchyroll в избранное», «покажи цены в рублях», «настрой для моего Sony». Он поменяет код, пересоберёт приложение и поставит его на ваш телевизор.

Поддерживается ли мой язык?

Английский, испанский, португальский, русский и немецкий. Язык берётся из настроек телевизора, или выберите его в настройках Free My TV. Нужен другой? Попросите Claude добавить его.

Собирает ли Free My TV какие-то данные?

Никаких аккаунтов, аналитики и отслеживания. Он обращается только к TMDB (рекомендации), Open-Meteo (погода для вашего города) и Binance (курсы).

Это бесплатно?

Да. Лицензия MIT, и ключ TMDB тоже бесплатный.
