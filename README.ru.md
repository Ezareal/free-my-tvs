# Free My TV

**Быстрый главный экран без рекламы для телевизоров Google TV, LG и Samsung.**

Популярное из ваших же приложений, погода перед глазами и оформление, которое меняется вместе с закатом.<br>
Открытый исходный код. Создано с помощью Claude Code. Всё возвращается одной кнопкой.

## Что вы получите

- **Без рекламы.** Ни спонсорских рядов, ни баннеров, ни роликов, которые запускаются сами. Ни одного.
- **Ваши приложения на первом плане.** Стриминговые сервисы, которыми вы действительно пользуетесь, в стеклянном ряду избранного. Какие и в каком порядке, вы выбираете прямо на телевизоре.
- **Популярное без спонсоров.** Каждый час три новые рекомендации из того, что в тренде на этой неделе, и из новинок. Только из тех приложений, которые у вас уже есть. У фильмов и сериалов свои вкладки.
- **Погода и курсы в одно нажатие.** Прогноз по часам, восход и закат, свежие курсы криптовалют.
- **Днём светло, ночью темно.** Оформление меняется по настоящему закату в вашем городе, как на телефоне.
- **Заставка в тон.** Полноэкранные фото рекомендаций с большими стеклянными часами.
- **Быстро.** 60 кадров/с, каждый кадр за 16,6 мс, на собственном чипе телевизора. Главный экран занимает 96 МБ памяти вместо 242 МБ (−60%).<br><sub>Измерено на 98″ TCL Google TV под Android 14.</sub>
- **Настройка прямо на телевизоре.** Язык, город, температура, тема, виджеты погоды и курсов, какие монеты показывать и какие приложения в избранном. Всё в собственных настройках Free My TV.
- **Безопасно.** Root-права не нужны, ничего не удаляется, а одна кнопка возвращает заводской главный экран.

## Установка

Займёт около десяти минут. Нужны Google TV или Android TV (Android 9 или новее) и компьютер в одной сети Wi-Fi.

### Простой способ: Claude Code

С Claude Code можно говорить по-русски: он и ответит по-русски.

1. **На телевизоре** включите режим разработчика. Откройте Настройки → Система → Об устройстве и семь раз нажмите на *Сборка ОС Android TV*. Затем откройте Настройки → Система → Для разработчиков и включите параметр **Отладка по USB**. Запишите IP-адрес телевизора (Настройки → Сеть и Интернет).
2. **На компьютере** скачайте код:
   ```bash
   git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv
   ```
3. **Откройте [Claude Code](https://claude.com/claude-code) в этой папке** и напишите:
   > Установи Free My TV на телевизор 192.168.1.50. Я живу в Москве.

   Claude Code установит нужные инструменты, соберёт приложение и поставит его на телевизор. Замените IP-адрес и город на свои.
4. **На телевизоре** откройте *Free My TV* → *Главный экран* → *Free My TV* и разрешите отладку по USB: отметьте *Всегда разрешать с этого компьютера*.

### Ручной способ

1. **На телевизоре** выполните шаг 1 выше.
2. **Инструменты:** JDK 17 или новее, утилиты командной строки Android SDK (build-tools 34, platform android-34) и adb. На Mac:
   ```bash
   brew install --cask temurin android-commandlinetools android-platform-tools
   sdkmanager "build-tools;34.0.0" "platforms;android-34"
   ```
   На Linux возьмите OpenJDK 17, утилиты командной строки Android и adb из менеджера пакетов, затем выполните ту же команду `sdkmanager`. На Windows используйте WSL.
3. **Сборка:**
   ```bash
   ./build.sh
   ```
   Первый запуск создаст `config.properties`. Укажите в нём свой город и [ключ TMDB](#ключ-tmdb), затем запустите скрипт снова.
4. **Установка:**
   ```bash
   adb connect 192.168.1.50:5555
   adb install -r FreeMyTV.apk
   ```
   На телевизорах TCL также разрешите приложению работать в фоне (TCL по умолчанию это запрещает, и тогда переключение не запустится):
   ```bash
   adb shell "appops set io.freemytv AUTO_START allow || appops set io.freemytv APP_AUTO_START allow"
   ```
5. **На телевизоре** откройте *Free My TV* → *Главный экран* → *Free My TV*.

## Телевизоры LG (webOS)

Тот же главный экран в виде приложения для LG: рекомендации, стеклянный ряд избранных приложений, нижняя панель с входами, погодой и курсами, день и ночь, раздел *Настройки* и редактор избранного. Установка идёт через приложение LG **Developer Mode**, без root-прав и без изменений на телевизоре. Главный экран LG остаётся на месте, а Free My TV открывается одним нажатием цифровой кнопки.

Нужны телевизор LG с webOS 3 или новее и компьютер с Python 3 в той же сети Wi-Fi.

1. **На телевизоре** откройте LG Content Store и установите **Developer Mode**. Войдите в бесплатный [аккаунт разработчика LG](https://webostv.developer.lge.com) и включите **Dev Mode Status** (телевизор перезагрузится). Затем включите **Key Server** (сервер ключей). Запишите IP-адрес и кодовую фразу (passphrase), которые покажет приложение.
2. **На компьютере** скачайте код и соберите приложение. `config.properties` работает так же, как для Google TV (ваш город и [ключ TMDB](#ключ-tmdb)):
   ```bash
   git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv
   python3 webos/build.py
   ```
3. **Установка.** При первой установке скрипт спрашивает кодовую фразу телевизора, при обновлениях не спрашивает:
   ```bash
   python3 webos/install.py 192.168.1.50
   ```
4. **На телевизоре**, пока открыт Free My TV, нажмите и удерживайте цифровую кнопку на пульте. С этого момента она открывает Free My TV откуда угодно.

С Claude Code скажите: *«Установи Free My TV на телевизор LG по адресу 192.168.1.50. Я живу в Москве.»* Claude Code соберёт приложение и даст команду для установки, а кодовую фразу вы введёте сами.

Режим разработчика действует около 40 дней. Время от времени откройте приложение **Developer Mode** и нажмите **EXTEND** (продлить). Чтобы удалить Free My TV, выполните `python3 webos/install.py 192.168.1.50 --uninstall`.

## Телевизоры Samsung (Tizen)

Тот же главный экран в виде приложения для Samsung, со всем, что есть в версии для LG: рекомендации, избранные приложения, нижняя панель с входами, погода и курсы, день и ночь, а также собственные настройки. Установка идёт через собственный режим разработчика Samsung, без root-прав и без изменений на телевизоре. Главный экран Samsung остаётся на месте.

Нужны телевизор Samsung 2017 года или новее (Tizen 3+) и компьютер в одной сети Wi-Fi.

1. **На телевизоре** откройте **Приложения** и наберите на пульте `1 2 3 4 5`. Включите **Режим разработчика**, введите IP-адрес компьютера в поле **Host PC IP** и перезагрузите телевизор.
2. **На компьютере** скачайте [TizenBrew Installer](https://github.com/reisxd/TizenBrewInstaller/releases/latest), установщик для телевизоров Samsung от сообщества. Откройте его и подключитесь к телевизору.
3. **Установка с GitHub:** введите `simbasjungles/free-my-tv`. На телевизорах 2023 года и новее установщик один раз попросит войти в аккаунт Samsung, чтобы подписать приложение для вашего телевизора.
4. **Сразу в приложение:** в настройках телевизора, в параметрах начального экрана (*Start Screen Options*), включите **Автозапуск последнего приложения** (Autorun Last App). Телевизор будет включаться сразу в Free My TV.

Эта сборка берёт город из часового пояса телевизора. Чтобы указать свой точный город и получать рекомендации, соберите приложение со своими `config.properties` и [ключом TMDB](#ключ-tmdb). Откройте папку в Claude Code и напишите: *«Установи Free My TV на телевизор Samsung по адресу 192.168.1.50. Я живу в Москве.»* Claude Code настроит инструменты Samsung. На телевизорах 2023 года и новее вы войдёте в аккаунт Samsung в браузере, чтобы создать сертификат.

## Настройки

Исходные значения берутся из `config.properties`, который создаёт первая сборка. Для Google TV, LG и Samsung используется один и тот же файл. Комментарии в нём написаны по-английски, а эта таблица объясняет каждый ключ. Большую часть значений можно поменять и на телевизоре: *Free My TV* → *Настройки*. Выбор на телевизоре важнее:

| Ключ | Что делает | По умолчанию |
|---|---|---|
| `tmdb_key` | Ваш бесплатный ключ TMDB для рекомендаций | пусто |
| `tmdb_region` | Ваша страна (две буквы): какие фильмы и сериалы есть в каких приложениях | `US` |
| `latitude`, `longitude` | Ваш город, для погоды и заката | Нью-Йорк |
| `city` | Название на карточке погоды | пусто (на карточке «Погода») |
| `language` | `auto` (как на телевизоре), `en`, `es`, `pt`, `ru` или `de` | `auto` |
| `show_crypto` | Показывать курсы криптовалют с Binance на главном экране и в заставке | `true` |
| `currency` | Валюта курсов криптовалют: `USD`, `EUR`, `RUB`, `BRL`… | `USD` |
| `temperature` | `C`, `F` или `auto` | `auto` |
| `disable_assistant` | Также отключать Google Assistant | `false` |

Поменяли что-то? Запустите `./build.sh` и установите приложение заново. Сохраните `freemytv.keystore`: обновления подписываются им.

### Ключ TMDB

Ключ бесплатный, получить его можно за две минуты. Создайте аккаунт на [themoviedb.org](https://www.themoviedb.org/signup), откройте [Settings → API](https://www.themoviedb.org/settings/api) и запросите ключ разработчика. Вставьте *API Read Access Token* (или *API Key*) после `tmdb_key=`. Ключ ваш: файл `config.properties` не попадает в git.

## Возврат к заводскому

На телевизоре: *Free My TV* → *Главный экран* → *Заводской*. Заводской главный экран, заставка и все приложения возвращаются точно такими, какими были. Если новый главный экран упадёт три раза за пять минут, Free My TV сам вернёт заводской.

Чтобы удалить Free My TV насовсем, сначала переключитесь на *Заводской*, затем удалите *Free My TV* (Настройки → Приложения).

## Что меняется

- Free My TV становится главным экраном и заставкой.
- Отключаются, но не удаляются:
  - заводские главный экран и заставка;
  - запасной главный экран Google TV, Play Games и YouTube Music;
  - на телевизорах TCL: TCL Channel, сообщения, демо-режим магазина, меню для отелей, руководства, приложения для зеркалирования экрана и сбора логов;
  - на телевизорах Philco: AI PONT (рекламные каналы и загрузка приложений) и руководство;
  - на телевизорах Multilaser: распознавание содержимого экрана (ACR) от Anoki, демо-режим магазина и руководство;
  - Google Assistant, только при `disable_assistant=true`.
- На телевизорах TCL кнопки Netflix, YouTube и Prime на пульте продолжают работать через небольшую службу специальных возможностей, которая только читает эти кнопки. Выберите, что открывает каждая кнопка, в *Free My TV* → *Кнопки пульта*. Режим *Заводской* отключает эту службу. На телевизорах Vestel (F&U и другие собственные марки магазинов) то же относится к кнопке Netflix.
- Изображение, звук, входы, сопряжение пульта, сервисы Google и Play Store входят в защищённый список и проверяются перед каждым изменением.
- Приложения, которые сохранили Wi-Fi-сеть, никогда не отключаются: иначе Android удалит эту сеть. Если первоначальная настройка телевизора сохранила вашу сеть, переключение сначала попросит забыть её и подключиться заново в Настройках → Сеть и Интернет. Сохранённые сети вне зоны действия там не показываются: Claude Code может удалить их.

## Любой телевизор

Free My TV работает на Google TV и Android TV: TCL, Sony, Hisense, Philips, Xiaomi, телевизоры Vestel (F&U) и другие, а также приставки вроде Chromecast with Google TV, Google TV Streamer, onn 4K и NVIDIA Shield. А на телевизорах [LG](#телевизоры-lg-webos) и [Samsung](#телевизоры-samsung-tizen) он работает как приложение.

**Любой другой телевизор:** подключите приставку Google TV к HDMI и избавьте этот телевизор от рекламы. Те же шаги, тот же главный экран.

**Другая марка или модель:** спросите Claude. Free My TV сделан так, чтобы его можно было адаптировать с помощью ИИ. Откройте папку в Claude Code и напишите *«Настрой его для моего Sony»*: Claude Code изучит телевизор, найдёт его главный экран и рекламные приложения, обновит списки ниже и проведёт вас через проверку. [CLAUDE.md](CLAUDE.md) рассказывает ему, как это делать.

| Что | Где |
|---|---|
| Приложения для отключения | `DEBLOAT` в [`HomeMode.java`](app/src/io/freemytv/HomeMode.java) |
| Приложения, которые нельзя трогать | `PROTECTED` в том же файле |
| Приложения в избранном | `SHELF` в [`HomeApps.java`](app/src/io/freemytv/HomeApps.java) |
| Приложение с телеканалами вашей марки | `LIVE_TV_APPS` в том же файле |

## Как это работает

- **Обычное приложение для Android, без Gradle и библиотек.** [`build.sh`](build.sh) запускает aapt2 → javac → d8 → zipalign → apksigner и собирает APK размером 2 МБ.
- **Использует ADB самого телевизора, изнутри телевизора.** Приложение подключается к `127.0.0.1:5555` своим ключом (это и есть запрос *Разрешить отладку по USB?*) и выполняет те же команды, которые выполнили бы вы: `cmd package set-home-activity`, `settings put secure screensaver_components`, `pm disable-user`. Подключений из сети приложение не принимает.
- **Рисуется вручную на одном Canvas.** Матовое стекло и небо построены шейдерами Android 13. На Android 9–12 используется обычная заливка. На Android 9–11 тени облегчённые, а GPU-слои не используются, потому что видеочипы там старее.
- **Страховка.** Watchdog работает в отдельном процессе: после трёх сбоев за пять минут возвращает заводской главный экран. Проверка при загрузке сохраняет ваш выбор после обновлений телевизора.
- **На LG и Samsung тот же дизайн на обычных HTML, CSS и JavaScript** ([`web/`](web)), написанных для Chromium старых телевизоров, без фреймворков. [`webos/build.py`](webos/build.py) упаковывает его вместе с `config.properties` в `.ipk` без инструментов LG, а [`webos/install.py`](webos/install.py) устанавливает его через Developer Mode. На LG приложения перечисляются и открываются через служебную шину телевизора (Luna), как это делает лаунчер LG. [`tizen/build.py`](tizen/build.py) упаковывает то же приложение в пакет Samsung `.wgt`, а оно открывает приложения и входы через веб-API Tizen. Чтобы посмотреть на компьютере, выполните `python3 webos/build.py --preview`, затем откройте `out/webos/index.html` (вместо приложений телевизора там показан пример списка).
- **Данные** берутся из TMDB (популярные фильмы и сериалы, новинки и то, какие приложения что показывают в вашей стране), Open-Meteo (прогноз, восход и закат) и, по желанию, Binance (курсы за 24 часа, если `show_crypto=true`).

## Конфиденциальность

Никаких аккаунтов, аналитики и отслеживания. Приложение обращается к TMDB, Open-Meteo (с координатами, которые вы указали, или с главным городом вашего часового пояса) и к Binance, только если `show_crypto=true`. Ваши настройки остаются на вашем компьютере и телевизоре.
